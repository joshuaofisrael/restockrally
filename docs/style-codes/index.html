Where to find a style code

Nike and Jordan print the style code on the box label and on the tag inside the shoe, in the form of six characters, a dash and three digits. adidas and New Balance use their own article or model codes. See how to look up a Nike style code and how to check a Nike box label.

Codes, dates and prices come from the source cited on each shoe page. A code that is not listed here is not yet in our release calendar.
