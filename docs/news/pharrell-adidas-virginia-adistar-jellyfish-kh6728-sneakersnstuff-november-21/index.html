Pharrell's wildest adidas runner is back in a new "VIRGINIA" version, and it costs $300

By the RestockRally desk

The Pharrell Williams x adidas Originals VIRGINIA Adistar Jellyfish (KH6728) is listed at $300 at Sneakersnstuff US, with snkr_twitr also pointing to END. and Slam Jam on November 21.

Last updated November 21, 2026 at 9:05 AM ET

Pharrell Williams' strangest-looking adidas runner has a new version out today. "Virginia adidas Adistar Jellyfish by Pharrell," snkr_twitr posted on X on Saturday morning, in a post marked as an ad, pointing to Sneakersnstuff US, END. and Slam Jam.

Price and code

Sneakersnstuff US lists the pair as the "adidas Originals VIRGINIA Adistar Jellyfish By Pharrell Williams" under style code KH6728, at $300.

That code is one digit away from the original Pharrell x adidas Adistar "Jellyfish" (KH6727), which was on release calendars for November 1 at the same $300 price, as we noted in our November 1 to 7 release roundup. So this is a second version, not a restock of the first.

What the shoe is

The retailer describes it as one of Pharrell's "wildest adidas designs yet", saying it takes "the technical DNA of the Adistar running franchise" and pushes it "into almost alien territory". The store page does not explain what the "VIRGINIA" name refers to. Pharrell grew up in Virginia, but adidas and the retailer have not said the name is a nod to that, so treat it as a guess.

How to buy

The snkr_twitr post links three stores rather than adidas's own app, so stock depends on each shop. At $300 and with only a few retailers listed, sizes may be limited. Check each store's page for availability, shipping and returns before you buy, and compare the style code so you do not end up with the first version by mistake.
