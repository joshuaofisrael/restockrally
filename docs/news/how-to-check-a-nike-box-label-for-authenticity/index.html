How to read a Nike box label, and what it can tell you

By the RestockRally desk

Nike's size charts explain that the CM figure on a box or label is not your foot length. Here is how to compare a box label with the official product page, and what a label cannot prove on its own.

Last updated November 11, 2026 at 1:58 PM ET

A Nike box label is a useful checklist, not a complete authenticity test. The honest way to use it is to compare what is printed on the box or the in shoe label with the official Nike listing for that pair, especially the style code and the size. Nike itself warns shoppers about one common mixup: on both the men's and women's footwear size charts, it says the CM size displayed on shoe boxes and labels is different than Foot Length (cm).

What to match to the official page

Start with the style code, also called a style number or SKU. Nike prints it on product and SNKRS launch pages. On 11 November 2026, the SNKRS page for the Kobe 8 Protro "Shanghai Fireworks" listed SKU IO6259 800. If a box, a listing or a seller uses a different code, you are not looking at the same colorway. We explain how to search from a code in How to look up a Nike style code or SKU.

Then check the size. Nike's charts list US, UK, EU and CM/JP figures for each size, plus a Foot Length row. The number to compare with your measured foot is the Foot Length figure, not the CM printed on the box. If a label shows a US size, also look at the other size systems on the same official chart so the UK, EU and CM/JP figures agree with that US size. A mismatch between the box and Nike's chart for that size is a reason to pause and ask the seller to explain, or to buy from the brand or retailer directly instead.

What a label cannot prove

A printed style code and size, even when they match Nike's page, do not by themselves prove that a pair is new, unworn, or sold by the store named in an ad. Labels can be copied. This page does not list secret "tells," fonts or glue patterns, because Nike's public size charts and product pages do not publish a forensic guide, and an unofficial checklist can be wrong.

The more reliable path is the seller. Buy from Nike, or from a retailer you chose on purpose, using that company's own website, app or store. Foot Locker, Finish Line and similar stores list products on their own pages; start there rather than from a forwarded checkout link. For ads, raffles and "restock" messages that try to pull you off the official site, see how to spot a fake sneaker release ad or raffle.

Sizing details that often cause confusion

Because the CM on the box is not foot length, a shopper who measures 28 cm and then looks for "28" on the box can pick the wrong size. Use Nike's chart: measure as described in How to measure your foot at home, match the Foot Length row, and only then read the US size and the CM/JP figure Nike assigns to that size. Kids' C and Y sizes have their own chart; see Nike kids' shoe sizes explained.

If you bought from Nike and the size is wrong, check Nike's return policy. Launch pairs can follow tighter terms, which we cover in SNKRS returns and Nike's terms of sale.
