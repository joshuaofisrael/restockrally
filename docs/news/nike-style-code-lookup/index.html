How to look up a Nike style code or SKU

By the RestockRally desk

Nike lists a style or SKU on its product and SNKRS launch pages. Here is how to use that code to find the matching official listing, and how we write codes on this site.

Last updated November 11, 2026 at 1:56 PM ET

Nike identifies each colorway with a style code, also called a style number or SKU on its own pages. The official listing is the place to confirm the name, price and date, not a screenshot or a reseller caption. On 11 November 2026, for example, Nike's SNKRS launch page for the Kobe 8 Protro "Shanghai Fireworks" identified that colorway as SKU IO6259 800 and listed a $200 price.

Where Nike prints the code

On a SNKRS launch page, look for the SKU or style in the product details. Regular nike.com product pages also list a style number in the product details, next to the color name. Archive and history pages can use the same kind of identifier; Nike's Air Jordan 11 archive page, for example, lists a style code for the original white, black and Dark Concord pair.

The same code may also appear on a shoe box or on a label inside the shoe. When you compare a box to a listing, use the full code, including the three digits after the main block. On this site we write style codes with a space instead of a hyphen, so IO6259 800 is the same identifier as the hyphenated form on Nike's page.

How to look the code up

The most reliable search is on Nike's own site or in the SNKRS app. Paste the full style code into the search box on nike.com, or open the launch or product URL if you already have it. If the result is the same model name, colorway and code, you have the official listing. If the result is a different code, you are looking at a different colorway, even when the silhouette is the same.

Retailers such as Foot Locker and Finish Line also often print the Nike style code on their product pages. That is useful for matching inventory, but the brand's page remains the source for the official name and, when Nike has listed one, the retail price. A third party calendar can lag or use a nickname; if the codes do not match, treat them as different shoes.

What a code can and cannot tell you

A style code identifies a colorway. It does not, by itself, tell you the price, the launch time, whether a size is in stock, or whether a listing is a restock. Those facts come from the current product page. It also does not prove that a pair is new or that a seller is the store you think it is. For that, start from the official URL and be cautious of ads that only show a code; see how to spot a fake sneaker release ad or raffle.

We put the style code early in shoe pages and news posts so you can compare listings. The release calendar also includes style codes where we have them from the brand or a credited retailer page.
