The G-Unit G6 sold out instantly this summer, and the original colourway is back today for $130

By the RestockRally desk

Reebok lists the G-Unit G6 at $130 under style code 100289469. The Source set 20 November at 10 a.m. ET.

Last updated November 20, 2026

If you missed the G6 in the summer, the original colorway is back on a set clock. The Source published the plan on 18 November: the G-Unit x Reebok G6 returns Friday 20 November at 10 a.m. ET through Reebok.com, Foot Locker, and select retailers, at $130.

What Reebok's page showed

Reebok's product page titles the pair "Reebok x G-Unit G6 Men's Shoes," lists the color as white, blue and red, and prices it at $130. The style code on that page is 100289469. Each size is its own SKU built from that code. The run goes from 3.5 to 13 in half sizes, plus 14. That matches The Source's sizes, 3.5 through 13 plus a 14. The page title says men's. The Source calls the same run unisex. Check the size label on the retailer page before you pay.

When we loaded Reebok's page around 11 a.m. Eastern on 20 November, the page marked 20 of those 21 sizes available. Size 12.5 was the one marked unavailable. That is a snapshot from about an hour after the 10 a.m. time The Source gave, not a promise any size is still there.

The shoe The Source described

This is the original red, white and blue colorway from 2003. The Source describes a white leather and suede upper, a rubber midsole, and an icy outsole. It also says the summer release sold out immediately, which is why this date was announced two days ahead rather than as a surprise drop.

"The people showed us they still want the G-Unit. After seeing how quickly the first drop moved, we knew we had to bring back the OG colorway. This one is for the day-one fans and everyone who missed out the first time," 50 Cent said, according to The Source.

How this drop is set up

This is not a SNKRS draw. The Source names a clock time and three doors: Reebok's site, Foot Locker, and unnamed select retailers. The @snkr_twitr account flagged the white, blue and red pair on Friday morning and linked DTLR and Shoe Palace. Those links are affiliate links, so the price and the stock there can differ from Reebok's $130 page.

A pair that already sold out once draws copycat ads. Start from Reebok's product page or from Foot Locker's own site, not from a message.
